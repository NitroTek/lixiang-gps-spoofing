# ProUnbound

Android-приложение для подмены GPS с двумя режимами и опциональным автоотключением.

Пространство имён и идентификатор приложения: `kz.prounbound`.
При переходе с `com.github.fakegps` приложение устанавливается отдельно;
в настройках разработчика нужно заново выбрать ProUnbound для фиктивных местоположений.

- Одна кнопка запуска и остановки.
- Режимы: движение по кольцу G30 или неподвижная случайная точка материкового Китая.
- Опциональный таймер от 1 секунды до 5 минут, по умолчанию отключён.
- По истечении таймера тестовые GPS-провайдеры удаляются, подмена полностью снимается.
- Скорость 0–200 км/ч, по умолчанию 90 км/ч; изменяется во время движения.
- 0 км/ч удерживает текущую координату, продолжая публикацию GPS.
- После завершения круга движение продолжается с начала без разрыва координат.
- Фоновая работа, уведомление с кнопкой остановки, работа с выключенным экраном.
- Без интернета, закладок, джойстика, плавающих окон и ручного ввода маршрута.

## Неподвижная точка и таймер

В режиме «Стоять в случайной точке Китая» при каждом запуске выбирается новая
координата внутри материковой части страны. Она не меняется до остановки,
а публикуемая скорость всегда равна 0. Ползунок скорости в этом режиме скрыт.

Граница встроена в `app/src/main/assets/china-mainland.csv` и получена из
[Natural Earth Admin 0 Countries (1:110m)](https://www.naturalearthdata.com/downloads/110m-cultural-vectors/110m-admin-0-countries/).
Точки выбираются с отступом 0,5 градуса от границы на этой карте, чтобы избегать
пограничных и прибрежных участков. Источник данных: Natural Earth, public domain.

Таймер настраивается перед запуском и отсчитывается по монотонному времени
Android. Остаток времени виден на экране и в уведомлении. Изменение скорости
не перезапускает таймер. Пока подмена активна, выбор режима и настройки таймера
заблокированы. После остановки можно изменить их и запустить новую сессию.
Без таймера оба режима работают до ручной остановки. Настройки сохраняются.

## Маршрут

Встроен в `app/src/main/assets/g30-loop.gpx`: 173 точки, около 57,07 км.
Старт и финиш: **43.039292, 90.718589** — исходная точка, привязанная к G30.
Маршрут проходит через **43.138037, 90.894309**, возвращается по другой стороне
G30 через западное соединение и замыкается на старте.

Источник: расчёт OSRM / OpenStreetMap, полученный 05.10.2026.
Это геометрия дорог из карты; доступность съездов в реальном времени не проверена.
Сервисная оценка 42 минуты относится к обычному автомобильному маршруту.
Приложение движется с выбранной постоянной скоростью, в том числе на съездах;
при 90 км/ч полный круг занимает примерно 38 минут.

## Запуск

1. Установить APK (Android 5.0 / API 21 или новее).
2. Включить геолокацию Android.
3. В настройках разработчика выбрать **ProUnbound** как приложение для
   фиктивных местоположений.
4. Выбрать режим, настроить скорость для G30 и при необходимости включить таймер.
   Нажать **Запустить подмену GPS**.
5. Разрешить доступ к местоположению. Разрешение на уведомления желательно:
   оно позволяет видеть фоновую работу и остановить её из уведомления.
6. Открыть нужное приложение навигации: оно получает подменённые GPS-координаты.

Кнопка **Остановить** снимает подмену и возвращает системные провайдеры.
Следующий запуск G30 начинается с начала маршрута, а неподвижный режим выбирает новую точку. Закрытие экрана приложения
и поворот устройства не останавливают активный маршрут.
После принудительной остановки или уничтожения процесса системой запускать
маршрут нужно вручную. Приложение не запускается при загрузке устройства.
Некоторые приложения и прошивки игнорируют фиктивные местоположения.

## Сборка и проверки

Нужны JDK 17 (или совместимый с Gradle 8.11.1 JDK 21) и Android SDK 34.

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

APK: `app/build/outputs/apk/debug/ProUnbound.apk`.

Тесты проверяют движение по расстоянию и времени, смену скорости, нулевую
скорость, прохождение нескольких кругов, встроенный GPX, выбор неподвижных точек
внутри Китая и границы автоотключения для обоих режимов. Проверка подмены GPS
на устройстве: координата меняется вдоль дороги, поле скорости соответствует
ползунку, движение продолжается в фоне, после остановки подмена снимается.
